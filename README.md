# AIVRM — Dark Story Mode
### "Education, Connected."

A cinematic, scroll-driven, spatial education-management experience built from zero.

---

## 🌟 Narrative Architecture: The 9 Chapters

1. **Chapter 00 — Enter**
   - Immersive dark environment with 3D Earth, glowing atmospheric rim, and architectural campus foundations.
   - Precision floating authentication card with real stateful credentials verification (`admin@aivrm.edu`).
   - "Education, Connected."

2. **Chapter 01 — The Ecosystem**
   - Global view connecting students, partner institutions, and opportunities across 24+ countries.
   - Interactive 3D Earth alignment to selected sovereign telemetry nodes (India, UAE, USA, UK, Singapore).
   - Real-time applicant metrics: 12,842 Students (+8.4%), 1,284 Applications (+12.8%), 24+ Countries (+8.2%), 120+ Partner Institutions (+14.2%).

3. **Chapter 02 — The Flow**
   - Real-time spatial data pipeline visualizing applicant progression through luminous 3D spline nodes:
     `Application Submitted` ➔ `Document Verification` ➔ `Review In Progress` ➔ `Payment Received` ➔ `Approved & Enrolled`.
   - Dynamic stage inspection with volume breakdowns and status counts.

4. **Chapter 03 — People**
   - The human core of education: *"Students are not data points. They're futures."*
   - Featured candidate dossier: Rahul Sharma (B.Tech Computer Science, ADM-2026-001, Approved).
   - Telemetry gauges: 92% Attendance, ₹1,20,000 Fees Paid, 8.6 CGPA, 48/160 Credits.
   - Interactive student cohort carousel (Rahul Sharma, Priya Mehta, Arjun Rao, Sneha Iyer, Karan Singh, Aisha Khan).

5. **Chapter 04 — The Institution**
   - Spatial living campus architecture with wireframe prisms, beacons, and concentric courtyards.
   - 6 live spatial metric badges: Students (12,842), Academics (320 Courses), Attendance (92% Avg), Inventory (1,248 Items), Revenue (₹48.6L), Faculty (284 Members).
   - Telemetry tabs: Real-Time Overview, Academic Departments, and Spatial Infrastructure Facilities.

6. **Chapter 05 — Intelligence**
   - High-fidelity analytical environment:
     - Admissions Overview: Custom interactive SVG spline area chart with monthly hover tooltips.
     - Revenue Trend: Glowing spline curve tracking ₹42.1L (+12.6%).
     - Student Distribution: Custom SVG donut chart (Engineering 42%, Management 24%, Science 18%, Arts 10%, Others 6%).
     - Top Programs & Regional heat matrices.

7. **Chapter 06 — Every Application**
   - High-precision digital candidate dossier with search, filtering, and cryptographic audit signatures.
   - Verified chronological timeline and comprehensive student demographic records.

8. **Chapter 07 — The Network**
   - Camera pulls back into a global constellation linking Student ➔ Department ➔ Institution ➔ City ➔ Country ➔ World.
   - Partner hub nodes (Stanford, Cambridge, IIT Delhi, NUS, Dubai, Toronto) with live student transit tracking.

9. **Chapter 08 — The Future**
   - Minimal cinematic finale scene with infinity gateways, dawn beacon, and horizon perspective lines.
   - *"Education without boundaries. Shaping A Brighter Tomorrow."*
   - Direct gateway to the live AIVRM institutional dashboard workspace.

## ⚙️ Spatial & Interactive Features

- **Three.js WebGL Engine**: 3D Earth globe with particle continents, atmospheric Fresnel rim shader, Great Circle bezier arcs with traveling pulse particles, 3D architectural campus pavilions, and dawn light pillar.
- **Scroll & Keyboard Choreography**: Scrubbing with scroll or using keyboard keys `0`-`8`, `PageUp`/`PageDown` or `ArrowUp`/`ArrowDown` navigates chapters with smooth camera lerping.
- **Command Palette (`⌘K` / `Ctrl+K`)**: Instant search and teleportation across chapters, student dossiers, and analytics.
- **Synthesizer Soundscape**: Built-in Web Audio API generative ambient pad (D minor / F maj9 chord) with low-pass filter and spatial modulation.
- **Device-Aware Design**: Fully responsive across ultra-wide desktop, laptop, tablet, and mobile views.
